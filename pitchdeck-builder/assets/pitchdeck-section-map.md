# Pitch-deck section map (plugin-level reference)

This is the canonical section list used by the `pitchdeck` skill. The skill's own
`references/section-map.md` is the runtime reference with audience defaults and
consolidation rules. This file mirrors brandbook-builder's `assets/brandbook-section-map.md`
so the plugin shapes match.

1. Cover
2. Problem
3. Solution
4. Market
5. Product
6. Traction
7. Proof
8. Business Model
9. GTM
10. Team
11. Roadmap
12. Ask / Next step

## Optimization for smaller decks

Sub-12-slide decks consolidate as follows:

- Merge **Market + Business Model** for early-stage investor decks.
- Merge **Product + Solution** when there is one screen to show.
- Replace **Proof** with a Cover logo strip for very early sales decks.
- Drop **Roadmap** for sales decks unless the prospect explicitly asks about timeline.

Cover and Ask are mandatory in every shipped deck.
